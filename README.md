# Chess Crack

## الهدف
حل الشطرنج حلاً كاملاً، بالبدء من عدد الأوضاع الكلي وتطبيق قوانين مضمونة تستبعد الاحتمالات خطوة بخطوة

## القواعد الثابتة
- أي استبعاد لازم يكون مضمون 100%، مش "غالباً صح"
- قوانين نقلاتنا ممكن تكون تقريبية، قوانين نقلات الخصم لازم تكون مثبتة
- تقييم Stockfish تخمين مش إثبات، ماعدا المات اللي بيلاقيه ونتايج Syzygy
- كل قانون يتسجل في log بوصفه وسبب إنه مضمون وتأثيره
- بنتابع رقمين: حجم مساحة الأوضاع وحجم شجرة الإثبات

## الهيكل
- engine: Stockfish 19 (نسخة macOS ونسخة Linux arm64)
- tablebases: Syzygy لحد 5 قطع (145 ملف WDL و145 ملف DTZ)
- src: الكود
- log: سجل القوانين والقياسات

## التشغيل
pip3 install -r requirements.txt
